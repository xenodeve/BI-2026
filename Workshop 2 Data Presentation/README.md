# Workshop 2 - Data Presentation

ไฟล์ส่งงาน: **Workshop2_Data_Presentation.xlsx** และ **Workshop2_Data_Presentation_Report.pdf** (ภาษาไทย 4 หน้า)

ข้อมูลประชากรมกราคม 2569 จาก `สถิติจำนวนประชากร_พื้นที่ ทั่วประเทศ.xlsx` มี 77 จังหวัด รวม **65,788,661 คน**. ไฟล์มี 4 ชีต (Presentation, Province Ranking, Raw Data, Cleansed Data) และกราฟ Excel ที่แก้ไขได้ 3 กราฟ: 10 จังหวัดสูงสุด, เพศ และสัญชาติ.

ตรวจแล้ว: คัดลอกค่าต้นทาง 1,573 เซลล์ตรงกัน, ยอดกลุ่มย่อยทุกจังหวัดตรงกัน, กราฟผูกช่วงข้อมูลจริง, คำนวณซ้ำไม่พบ formula errors. กรุงเทพมหานคร 5,419,484 คน; 10 จังหวัดสูงสุดรวม 21,178,217 คน. ไฟล์ต้นทางและ XLSX ส่งงานคง bytes เดิมตลอดการตรวจ.

**หลักฐาน native Excel ยังรอ:** เปิดโดยไม่มี repair dialog, ตรวจ 4 ชีต/3 กราฟ, บันทึกสำเนาแล้วปิดและเปิดซ้ำ. ภาพใน PDF เป็นการเรนเดอร์จากไฟล์แบบอ่านอย่างเดียว ไม่ใช่ screenshot จาก Excel GUI.

แหล่งบทเรียน: `Presentation/BI03 Data Presentation.pdf`. ต้นทาง Excel เก็บไว้ครบและไม่ได้แก้ไข. รายงานมีผลตรวจและวิธีเก็บหลักฐานจริงที่ยังรอ. ข้อมูลตรวจละเอียดอยู่ใน `support/functional_verification.json`.
